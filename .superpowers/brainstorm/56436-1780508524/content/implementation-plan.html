Four phases. Foundation first, then "wow" moments layered on top. Every change grounded in the UI/UX Pro Max skill recommendations and Modern Dark Cinema design system.

index.css · tailwind.config.js · ThemeProvider — everything else inherits from this
OLED Gradient Background + CSS Token Overhaul
Replace flat #090a0f with a true OLED gradient body background (#0a0a0f → #020203). Rewrite all CSS custom properties to the Modern Dark Cinema token set: --bg-deep, --bg-base, --bg-elevated, --surface, --accent, --accent-glow, --border, --easing. This single change affects every page instantly.

Inter Cinema Typography System
Apply the skill's weight/tracking discipline globally: font-weight: 800, letter-spacing: -1.5px on display sizes; 600, -0.5px on H2/H3; 500 + uppercase + 1.2px tracking on all labels/eyebrows. Drop Space Grotesk — Inter owns this entire system.

Spring Physics Animation Primitives
Create a shared transitions.js config exporting Framer Motion variants: fadeUp, scaleIn, slideInLeft/Right, staggerContainer — all using cubic-bezier(0.16, 1, 0.3, 1) easing with spring damping. Add prefers-reduced-motion media query wrapper. Every animated component imports from here.

Landing Page — Public WOW Moments
LandingPage.jsx + shared nav/footer
★ Highest visitor impact
Hero: Typewriter Headline with Ember Burst on Load
Headline types in word-by-word with a spring bounce per word. On the final keyword ("buyers"), an ember burst fires from the text — 12 particles radiate outward then fade. The CTA button slides up with a glow pulse. Sub-headline fades in 300ms after headline completes. Creates a micro-story in 1.2 seconds.
WOW ✦
Scroll-Triggered Section Reveals with Depth Parallax
Each section uses Framer Motion useInView + whileInView: content slides up 40px + fades in as it enters viewport. Background accent orbs parallax at 0.3× scroll speed (CSS transform: translateY via scroll listener). No scroll-jacking — native scroll speed preserved, effects are purely cosmetic layers.
WOW ✦Perf ✓
Growth Steps: Horizontal Scroll Timeline (Desktop)
The 7-step LEARN→CONVERT flow becomes a sticky horizontal scroll track on desktop. As you scroll vertically, the active step advances left-to-right with a glowing progress line connecting them. Each step card flips/scales into focus. On mobile: vertical stacked reveals as before. This is the single biggest "we know what we're doing" moment.
WOW ✦
Pricing Cards: 3D Tilt + Glow on Hover
Cards respond to mouse position with a subtle 3D tilt (rotateX/Y ±8°, perspective: 800px). The "popular" card has a persistent indigo glow border that brightens on hover. Price numbers count up from 0 when the section enters view (CountUp animation, 600ms).
WOW ✦
Nav: Frosted Glass + Smart Shrink
On scroll: height compresses from 72px → 52px, backdrop-blur increases from 8px → 16px, border-bottom appears. Logo scales 1.0 → 0.85. Transition uses the spring easing. CTA button in nav gains a glow pulse every 8 seconds (draws eye without being annoying).

Waitlist Page: Countdown + Urgency Animation

Login/Signup: Centered Glass Form
Single centred frosted-glass card on the ember background. Input fields have a glowing indigo underline on focus (not a border-box, just the bottom). Error states shake with a spring physics oscillation. Password field has a smooth show/hide toggle.

P4
Dashboard & Private Pages
GrowthDashboard · ChatInterface · ContentQueue · Settings · AgentTheater · WorkflowBuilder
Dashboard: Metric Cards with Animated Count-Up + Sparklines
On dashboard load, all metric numbers count up from 0 with spring easing. Each metric card has a mini sparkline (SVG path with a draw animation). Cards use the glass surface with a glow border in the metric's semantic colour (green = revenue, indigo = content, amber = leads). Hovering a card lifts it 4px with a shadow bloom.
WOW ✦Dashboard
Sidebar Navigation: Magnetic Active Indicator
The active nav item has a glowing indigo pill indicator that smoothly animates position as you navigate (Framer Motion layoutId). Hovering inactive items shows a ghost indicator trailing the cursor. Icons scale 1.0 → 1.15 on hover with a spring bounce. Collapsed state shows icon-only with tooltip.
WOW ✦Dashboard layout
Agent Activity Theater: Live Pulse Visualization
Each active agent gets a pulsing ring animation (scale 1.0 → 1.3, opacity 1 → 0, repeat). Task progress bars fill with an animated shimmer. Completed tasks check off with a spring-bounced checkmark. The overall "system heartbeat" pulses a faint ember glow on the page border.
WOW ✦AgentTheater
Chat Interface: Streaming Message Animation
AI messages render word-by-word (streaming simulation if not already). User messages slide in from the right, AI from the left. Typing indicator uses three ember-coloured dots with a wave animation. Code blocks have a copy button that shows a "Copied ✓" confirmation with a spring pop.
